# Heroes of Might and Magic

A simple C# console project inspired by the Heroes of Might and Magic series.

## Features

- Turn-based battle simulation
- Unit classes with combat statistics
- Object-oriented design
- .NET 10
- Docker support

## Requirements

- .NET 10 SDK
- Docker (optional)

## Run

```bash
dotnet run
```

## Run with Docker

Build the image:

```bash
docker build -t heroes-game .
```

Run the container:

```bash
docker run -it --rm heroes-game
```

## Project Status

This project is being developed for learning C#, object-oriented programming, Git, and Docker.
