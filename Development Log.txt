## Update

**Date:** 2 August 2026

### AI Integration

Integrated a local Large Language Model (LLM) using Ollama.

### Changes

* Added an `AI` folder to the project.
* Implemented the `Narrator` class.
* Connected the game to Ollama through its HTTP API.
* Added asynchronous communication with the AI model.
* Implemented a loading animation while waiting for the AI response.

### Battlefield Narration

Before each battle, the game sends information about the participating armies to the AI model.

The model generates a short description of the battlefield, creating a more immersive atmosphere before combat begins.

### Current AI Features

* AI-generated battlefield descriptions.
* Local execution using Ollama.
* No internet connection required.
* Game mechanics remain fully controlled by the C# engine.

## Update

**Date:** 26 June 2026

### Unit Refactoring

The unit system was refactored to use inheritance.

### Changes

* Added separate classes for individual creatures.
* Introduced a faction-based folder structure.
* Moved creature statistics from `Program.cs` into dedicated unit classes.
* Simplified unit creation by instantiating specific creature types.

### Current Structure

```text
Models
└── Units
    ├── Unit.cs
    ├── Castle
    │   └── Pikeman.cs
    └── Necropolis
        └── Skeleton.cs
```

### Result

Units are now created as:

```csharp
Unit pikeman = new Pikeman(10);
Unit skeleton = new Skeleton(15);
```

instead of manually specifying all unit statistics.


## Technical Progress Report

**Date:** 24 June 2026

### Overview

This document summarizes the functionality implemented during the initial development phase of the project.

---

## Unit Model

Implemented a `Unit` class representing a combat unit.

### Properties

| Property    | Type   | Description                      |
| ----------- | ------ | -------------------------------- |
| Name        | string | Unit name                        |
| Count       | int    | Number of creatures in the stack |
| Attack      | int    | Attack attribute                 |
| Defense     | int    | Defense attribute                |
| MinDamage   | int    | Minimum damage value             |
| MaxDamage   | int    | Maximum damage value             |
| Health      | int    | Health per creature              |
| TotalHealth | int    | Total stack health               |

### Constructor

All unit parameters are required during object creation.

This prevents creation of incomplete unit instances.

---

## Damage System

Implemented a random damage generation system.

### Method

`GetDamage()`

### Behavior

Returns a random value within the configured damage range.

---

## Health System

Implemented stack health management.

### Method

`TakeDamage(int damage)`

### Features

* Reduces stack health.
* Prevents negative health values.
* Supports death detection.

### Property

`IsAlive`

Returns the current living state of the unit stack based on remaining total health.

---

## Army Stack System

Added support for creature stacks.

### Formula

`TotalHealth = Count × Health`

The system calculates and stores the total health pool for the entire stack.

---

## Battle System

Implemented a reusable battle method.

### Method

`Fight(Unit unit1, Unit unit2)`

### Features

* Round-based combat
* Random damage calculation
* Health tracking
* Death detection
* Winner determination

---

## Battle Output

Implemented console battle logging.

### Features

* Battle start information
* Round counter
* Attack notifications
* Damage reporting
* Health updates
* Death notifications
* Winner announcement
